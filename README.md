# MyPortfolio

Personal portfolio site for Jihye Jeon (전지혜), Java and Spring Boot developer.

Static site, no build step: `index.html`, `styles.css`, `main.js`.

- **Add or edit a website project**: edit the `PROJECTS` list at the top of `main.js`.
- **Screenshots**: `assets/shots/<name>.webp` (960×600). Set `shot: "<name>"` on the project.
- **CV**: `assets/CV_JihyeJeon.pdf` (the Download CV button).

Run locally:

```bash
python -m http.server 5173
```

It can be hosted as-is on GitHub Pages, Netlify or Cloudflare Pages.
